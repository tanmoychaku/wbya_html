# WBYA HTML Homepage

Static homepage design for the West Bengal Yoga Association.

## Live URL

https://tanmoychaku.github.io/wbya_html/

## Files

- `index.html` - Main homepage.
- `about.html` - Themed About page converted from the original WordPress About content.
- `office-bearers.html` - Local Office Bearers page converted from the supplied WordPress table.
- `affiliated-units.html`, `associate-members.html`, `life-members.html`, `registered-players.html`, `our-pride.html` - Local member section pages linked from the Members menu.
- `background.html` - Animated SVG background graphic used by the homepage.
- `assets/css/styles.css` - Shared styles for all pages.
- `assets/js/main.js` - Shared JavaScript for mobile menu and homepage slider.

## Notes

- This is a static HTML/CSS/JavaScript project.
- No build step is required.
- Open `index.html` directly in a browser for local preview.
